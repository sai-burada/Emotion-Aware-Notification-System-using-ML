# Emotion-Aware Notification System using ML

## Overview

The Emotion-Aware Notification System is a Python-based application that detects user emotions using hand gestures and facial detection techniques. Based on the detected emotional state, the system filters notifications and provides personalized suggestions through an interactive GUI.

## Features

* Face Detection using OpenCV
* Hand Gesture Emotion Recognition using MediaPipe
* Emotion Fusion Logic
* Emotion-Based Notification Filtering
* Personalized User Suggestions
* Interactive GUI using Tkinter
* Real-Time Webcam Input

## Technologies Used

* Python
* OpenCV
* MediaPipe
* Tkinter
* Pillow
* NumPy

## Project Structure

* `vision/` → Face detection and hand gesture recognition modules
* `speech/` → Speech emotion module (under development)
* `fusion/` → Emotion fusion and decision logic
* `gui/` → Graphical User Interface
* `models/` → Future machine learning models
* `notification_engine.py` → Notification filtering logic

## Workflow

1. Capture webcam input
2. Detect face
3. Detect hand gesture emotion
4. Generate final emotion using fusion logic
5. Filter notifications based on emotion
6. Display results in GUI
